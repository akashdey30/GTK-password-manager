# Quick Run

Navigate to the project root (wherever you cloned it), then:

```bash
cd /path/to/GTK_Password_Manager && make run
```

> Replace `/path/to/GTK_Password_Manager` with the actual path on your machine.
> On Windows (MSYS2/UCRT64), this looks like `/c/Users/<YourName>/.../<repo>/GTK_Password_Manager`.
